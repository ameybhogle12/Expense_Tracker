# Agent Rules & Guidelines

## 📝 Documentation Maintenance Rule
Every time we come across a **major error**, a **complex problem**, or if we **successfully add a new feature**, you MUST proactively update the `APP_PROGRESS.md` file in the root of the workspace. 

*   **For New Features:** Add the feature to the correct section (Current or Premium).
*   **For Problems/Errors:** Log the problem faced, the root cause, and the exact solution or workaround implemented. 

This ensures a living developer log is maintained for the lifecycle of the project.
